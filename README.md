# 📋 Registration Form with Validation

Este projeto é um formulário de cadastro de usuários desenvolvido com HTML, CSS e JavaScript puro, com foco em validação de dados e experiência do usuário (UX).

---

## 🚀 Funcionalidades

- Formulário de cadastro completo
- Validação de nome, e-mail, data e gênero
- Verificação de senha (mínimo de 6 caracteres)
- Confirmação de senha
- Indicador de força da senha
- Feedback visual com cores e ícones
- Mensagens de erro dinâmicas
- Toast de sucesso e erro

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, variáveis e responsividade)
- JavaScript (validação e manipulação DOM)
- Tabler Icons
- Google Fonts

---

## 🎯 Objetivo do projeto

Este projeto foi criado para praticar:
- Manipulação do DOM com JavaScript
- Validação de formulários
- Experiência do usuário (UX/UI)
- Organização de código front-end
